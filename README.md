# Jastej Singh Sehra - Resume

This is the source code for my interactive resume, designed to be hosted on Vercel.

## Structure
- `index.html`: Main resume file.
- `assets/`: Static assets.
- `Preview images/`: Images used for link previews.
- `Showreel/`: Video assets.

## Deployment
Can be deployed directly to Vercel as a static site.
